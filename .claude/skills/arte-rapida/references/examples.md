# Exemplos de variacao de copy — arte-rapida

Cada exemplo cobre os mesmos `slotFields` do template em 3 registros diferentes:
**Direta**, **Sensorial** e **Descontraida**. Use como ponto de partida para gerar
as 3 opcoes de copy no Passo 4 da skill.

Todos os exemplos assumem o conjunto padrao de slot fields:
`Pre-titulo`, `Titulo`, `Subtitulo`, `Rodape-1`, `CTA`. Adapte se o template tiver
campos diferentes (ex: `Badge`, `Rodape-2`, `Pre-titulo-2`).

---

## Exemplo 1 — Almoco executivo com salmao

**Contexto:** restaurante de cozinha contemporanea, tom de voz descontraido mas elegante,
diferencial: insumos frescos.

### Direta
```
Pre-titulo: ALMOCO EXECUTIVO
Titulo: SALMAO NA BRASA
Subtitulo: Filezinho na grelha com legumes da estacao
Rodape-1: Seg a Sex • 11h-15h
CTA: Reserva ja
```

### Sensorial
```
Pre-titulo: HOJE NO MENU
Titulo: SALMAO QUE DERRETE
Subtitulo: Carne rosada, crocante por fora, suculento por dentro
Rodape-1: Almoco Executivo • 11h-15h
CTA: Vem provar
```

### Descontraida
```
Pre-titulo: TA NA HORA
Titulo: SALMAO TA NA BRASA
Subtitulo: Cancela o sushi do almoco. Hoje e na brasa.
Rodape-1: So no executivo • 11h-15h
CTA: Pede o teu
```

## Regras observadas nos exemplos

1. **Pre-titulo** sempre curto (1-3 palavras), MAIUSCULO. Funciona como rotulo/contexto.
2. **Titulo** e o destaque visual — frase de impacto, ate ~25 chars, geralmente MAIUSCULO.
3. **Subtitulo** completa a ideia do titulo — descritivo, ate ~60 chars.
4. **Rodape-1** carrega informacao funcional (horario, restricao, condicao). Use `•` como separador.
5. **CTA** e imperativo curto, sem ponto final. Pode ter humor.

## Quando o template tem campos extras

- **Badge** — palavra unica, geralmente promo/oferta (ex: "20% OFF", "NOVO", "GRATIS").
- **Rodape-2** — segunda linha de info funcional (ex: cardapio, telefone, instagram).
- **Pre-titulo-2** — usado em layouts com hierarquia dupla. Trate como variacao do Pre-titulo.

Se o template tem campo que voce nao sabe interpretar, peca contexto ao usuario antes de gerar.
Nao invente.
